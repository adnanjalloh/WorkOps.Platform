## What this release demonstrates

- a .NET 10 modular-monolith backend with explicit application, domain, infrastructure, contract,
  and HTTP boundaries;
- validated OIDC identity, active-membership tenant context, centralized permissions, default-deny
  query filters, save-time write guards, and cross-workspace regression tests;
- optimistic concurrency, request idempotency, atomic audit/outbox writes, confirmed RabbitMQ
  publication, manual acknowledgements, retries, and duplicate-safe effects;
- tenant-aware Redis caching, PostgreSQL-enforced quotas, bounded attachment handling, safe
  diagnostics, health checks, rate limiting, CORS, HSTS, and OpenTelemetry instrumentation;
- locked dependencies, warning-free release builds, coverage gates, CodeQL, dependency review,
  secret scanning, container scanning, and a runnable synthetic full-stack scenario;
- version and commit-addressed GHCR tags, an attached SPDX JSON SBOM, immutable digest evidence, and
  GitHub build-provenance plus SPDX SBOM attestations for the published digest.

## Run locally

Prerequisite: Docker Desktop. Then run:

```bash
./scripts/demo.sh --start
```

The scenario uses synthetic users and data, exercises the tenant and authorization boundaries, and
stores opaque local evidence under the ignored `.local/` directory without intentionally printing
or persisting tokens.

## Demonstration-only boundaries

- Keycloak users, credentials, and the direct-grant client exist only for the local synthetic demo.
- The development clean-scanner adapter is not a production malware-scanning service.
- Attachment storage is temporary local container storage, not durable private object storage.
- Telemetry instrumentation is present, but export and a monitored backend are not enabled by
  default.
- The repository demonstrates delivery controls; it is not a hosted production service and makes
  no uptime, throughput, penetration-testing, certification, or production-readiness claim.

## Known limitations

A real deployment still requires an operated OIDC provider, durable storage with backup and
recovery, monitored malware scanning, managed secrets, TLS and proxy configuration, telemetry
collection and alerting, and environment-specific operational validation.
